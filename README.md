One haiku about debugging, written by `main.py` to `/output/entry.txt`:

```
The stack trace unwinds
frame by frame, it points at me
line one: my own code
```

Three lines, 5-7-5 syllables (17 total), 77 characters. A stack trace unwinding
frame by frame until it stops accusing the system and points at the author's
own first line — the hunt ending where it started.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Standard library only, no network, no randomness — running it twice produces
byte-identical output.
